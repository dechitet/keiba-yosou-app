競馬予想ナビ — iPhone向けPWA試作版

内容
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面追加用の設定
- sw.js: 基本的なオフラインキャッシュ

iPhoneで試す方法
1. この一式をHTTPS対応のWebホスティングに配置してください（GitHub Pages等）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」を選択します。
4. 追加したアイコンからアプリ風に起動できます。

現時点の機能
- 出走馬・単勝オッズ・各評価項目の入力
- スコア計算と印表示
- CSV読み込み・予想結果CSV保存
- 予想履歴と購入額・払戻金・回収率の記録（ブラウザ内保存）

未実装・次段階
- リアルタイム出馬表・オッズ自動取得
- 過去レースデータの取り込み
- 学習済み予測モデル、勝率の校正、時系列バックテスト
- 複数端末間の同期、ログイン、通知

注意
自動データ取得は、データ提供元/APIの選定と利用条件の確認、サーバー側の実装が必要です。
この試作版のスコアは独自の入力評価に基づくもので、実証済みAIや勝率予測ではありません。
